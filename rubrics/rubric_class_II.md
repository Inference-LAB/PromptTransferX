# BehInt Rubric — Class II (Context-Sensitive Patterns)

**Applies to:** P02, P03, P06, P08, P09, P17, P19, P24

## Scoring criterion

Score the degree to which the core reasoning or interaction mechanism
prescribed by the pattern specification is activated in the output.

| Score | Description |
|---|---|
| **5** | Core mechanism fully activated; output clearly demonstrates the pattern's intended cognitive operation throughout |
| **4** | Pattern mechanism evident; minor lapses that do not undermine the core operation |
| **3** | Pattern partially activated; key mechanism present but incomplete or inconsistently applied |
| **2** | Pattern weakly evident; intended operation can be inferred but output would not be distinguishable from a no-pattern baseline |
| **1** | Pattern not activated; response is indistinguishable from a baseline response without any pattern |

## Key indicators by pattern

| Pattern | Primary indicator |
|---|---|
| P02 Output Automater | Complete, self-contained artifact produced with no placeholders |
| P03 Persona | Voice, vocabulary, and epistemic standards consistent with specified role |
| P06 Fact Check List | Per-claim verifiability structure present in output |
| P08 Question Refinement | Explicit reformulated question stated before answer |
| P09 Alternative Approaches | Three distinct approaches with explicit trade-off comparison |
| P17 CoT | Intermediate reasoning steps visible and logically connected |
| P19 Self-Consistency | Three independent paths attempted; majority vote stated |
| P24 Narrative-of-Thought | Temporal connectives used; reasoning presented as narrative arc |
