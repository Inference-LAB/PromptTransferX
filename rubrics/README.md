# Rubrics Directory

Per-class BehInt (Behavioral Intent) scoring rubrics for the three-judge protocol.

| File | Applies to |
|---|---|
| `rubric_class_I.md` | P05, P15, P18, P23 (Stable structural) |
| `rubric_class_II.md` | P02, P03, P06, P08, P09, P17, P19, P24 (Context-Sensitive) |
| `rubric_class_IIstar.md` | P07, P10, P16, P21 (Claude-Divergent) |
| `rubric_class_III.md` | P04, P12, P13, P14, P20, P22 (Model-Specific) |
| `rubric_class_IV.md` | P01, P11 (Brittle) |
| `rubric_pts_weights.md` | PTS weight calibration and sensitivity results |

All rubrics use a 1–5 integer scale, normalised to [0, 1] for the BehInt component of PTS.
