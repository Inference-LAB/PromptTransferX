# BehInt Rubric — Class I (Stable Structural Patterns)

**Applies to:** P05 Recipe/Template, P15 Context Manager, P18 Auto-CoT, P23 Chain of Draft

## Scoring criterion

Score the degree to which the model output correctly activates the
structural format prescribed by the pattern specification.

| Score | Description |
|---|---|
| **5** | All prescribed structural elements present and in the specified order; output is directly usable with zero reformatting |
| **4** | All elements present; minor ordering or labeling deviation that does not affect downstream usability |
| **3** | Most elements present; one structural section missing or significantly out of place |
| **2** | Partial structure; fewer than half the prescribed sections correctly instantiated |
| **1** | Structure not followed; response is unstructured prose with no recognisable template adherence |

## Key indicators

- **P05:** STEP headers present; LIMITATIONS and NEXT ACTIONS sections populated
- **P15:** Explicit scoping language present; no extra-context information introduced
- **P18:** Analogue example generated before main solution; both sections labelled
- **P23:** Draft steps ≤5 words each; "Answer:" section clearly separated

## Scoring notes

- Partial credit (2–4) is appropriate when structure is partially followed
- A score of 1 should be reserved for outputs that completely ignore the format
- Judge independently of task accuracy (Acc is a separate PTS component)
